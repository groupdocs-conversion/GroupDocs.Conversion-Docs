Complete scenarios for GroupDocs.Conversion for .NET. Each page solves one real problem end to end, with a runnable sample project on GitHub:

* [Convert untrusted uploads safely]({{< ref "conversion/net/use-cases/convert-untrusted-uploads-safely.md" >}}) — convert HTML and SVG files your users upload without letting them reach the network, read other files on the server or run scripts.
* [Convert email with attachments to PDF]({{< ref "conversion/net/use-cases/convert-email-with-attachments-to-pdf.md" >}}) — turn a message into one PDF, or the message and every attachment into separate files that never overwrite each other.
